# chatzip plugin

Lets Claude turn your AI data exports into one tidy zip: a folder per AI, a text file
per chat.

## What you can ask

- "Zip my AI chats" (attach your exports from Claude, ChatGPT, Gemini, Grok or DeepSeek)
- "Organize these exports into folders by AI"
- "Include the AI's replies too"

By default each text file holds only your own messages.

It works from the export files you give it. It cannot log in to your accounts.

Project: https://github.com/spencerrios64/chatzip

## Install

In Claude Code:

```
/plugin install chatzip --marketplace spencerrios64/chatzip
```

In the Claude app, download this folder as a `.plugin` file (a zip of the `plugin` folder) and open it in a chat.
